# Three-Tier-AWS-DevOps-Project
Build a three-tier web application with a frontend, backend, and database. Use Terraform for AWS infrastructure, Docker for containerization, Kubernetes/EKS for deployment, Jenkins and/or GitHub Actions for CI/CD, Ansible for configuration-management practice, Blue-Green deployment for release strategy, and Prometheus/Grafana for monitoring.
